# POPTRAP 0.2.0-rc.1

**Release candidate dated 2026-11-18; not published.** Python prints `POPTRAP 0.2.0rc1`. This candidate packages Phases 1–9 without replacing the terminal, simulation, Studio, or delivery architectures.

- Choose the wheel for the tested install path. The source archive includes the versioned source, tests, docs and build tooling. Verify `SHA256SUMS` and install from the bundled `runtime.lock` before installing the wheel with `--no-deps`.
- A first launch can use bundled defaults. `poptrap --init-config` creates a user file without replacing one, or save from **Settings**. Run `poptrap --check` for environment diagnostics and `poptrap --validate-config` for strict configuration validation.
- An earlier `0.1.0` development wheel can be upgraded in its virtual environment. The candidate reads the existing settings and presets in place, including the legacy version field. Back them up before any upgrade; uninstallation removes package files, not preferences or presets.
- Browser Studio and Control Center use separate one-use access links. Recipients must Accept then Launch. Keep creator links private and use the opt-in recipient listener only on trusted local networks.

Start with the [installation guide](../installation.md), [compatibility matrix](../compatibility.md) and [Phase 10 verification](../phase-10.md). This candidate does not attest to native Windows, macOS, Termux, Firefox, WebKit, or physical mobile/camera/Wi-Fi/Bluetooth interoperability.
