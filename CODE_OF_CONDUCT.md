# Code of conduct

Treat other contributors and users with respect. Give constructive feedback, welcome differing experience levels, and ask permission before involving anyone in a simulation. Do not harass, discriminate, threaten, reveal private information, or abuse an issue tracker or local-network feature.

These expectations apply to project discussions, issues, pull requests, and other project spaces. Maintainers may remove abusive content, limit participation, or refer issues to the hosting platform. If you experience or witness misconduct, contact a maintainer through a private channel they have made available, or use GitHub's abuse reporting tools. Do not publish sensitive details to request help.
